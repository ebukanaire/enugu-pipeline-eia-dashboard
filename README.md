## 🚀 Core Platform Features

### 1. Geospatial Risk Mapping (Geophysics Integration)
* **How it works:** Generates interactive spatial maps tracking vital soil parameters (Soil Resistivity and Subsurface pH) across critical Enugu nodes (e.g., Ugwu Onyeama, 9th Mile, Emene Industrial Area).
* **Engineering Action:** Leverages geophysical corrosion principles to dynamically flag pipeline segments cutting through highly acidic or low-resistivity soils (< 20 Ω·m) as **"Critical Monitoring Required."**

### 2. Real-Time EIA Tracker & Automated Reporting
* **How it works:** Simulates continuous monitoring of ambient air metrics (Methane $CH_4$ Leakage in PPM) near compressor facilities.
* **Engineering Action:** Triggers automated dashboard alarms if legal environmental thresholds are violated. Features a built-in **Compliance Report Generator** allowing supervisors to instantly download formal, time-stamped text logs for regulatory reviews.

### 3. Predictive Corrosion Analysis (Machine Learning)
* **How it works:** Deploys a trained Scikit-Learn `RandomForestRegressor` algorithm.
* **Engineering Action:** Accepts live soil pH and resistivity slider variations from field technicians to output the exact expected **Pipeline Wall Degradation Rate (mm/year)**, driving proactive, predictive cathodic protection schedules.

### 4. Acoustic Intrusion & Anti-Vandalism AI Engine
* **How it works:** Deploys a trained Scikit-Learn `RandomForestClassifier` simulating distributed fiber-optic acoustic sensor monitoring.
* **Engineering Action:** Processes signal frequencies (Hz) and ground vibration amplitudes (mm/s) in real-time. The AI model successfully separates safe environmental background noise (heavy rain, wind) or authorized vehicle movements from illegal third-party manual digging or mechanical pipeline drilling attempts.

## ⚙️ Direct Local Installation & Deployment Guide

To audit or run this platform locally on your machine, follow these steps:

1. Clone the repository and navigate inside the folder.
2. Ensure you have the `pipeline_telemetry.csv` file inside your root directory folder.
3. Install dependencies: `pip install -r requirements.txt`
4. Execute server script: `streamlit run app.py`
